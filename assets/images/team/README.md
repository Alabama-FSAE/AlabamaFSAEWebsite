# Team headshots

Place team member headshots in this folder, then add the file to that person's `photo` value in `data/team.json`.

- Use lowercase names with hyphens, for example `ainsley-shaw.jpg`.
- Crop to a 4:5 portrait at 800 × 1000 pixels, with the head near the top of the frame.

A person with no `photo` value shows their initials instead.
